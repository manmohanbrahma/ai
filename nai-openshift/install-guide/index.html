Install Guide

Nutanix Enterprise AI on Red Hat OpenShift

One script installs single-node OpenShift and Nutanix Enterprise AI (NAI) in a VM, on a remote server, or on bare metal. This runbook walks through a real VM install on the lab host, with the answers given, the logs it produced, and how to log in.

Author Manmohan BrahmaRun on 15 October 2026Script nai-on-openshift.shPlanning GuideAll guidesOpenShift 4.22.17NAI 2.8.1

1Overview

The script runs on a Linux host and asks every question first. After you confirm, it downloads the NAI files, prepares the host, installs OpenShift, adds the operators NAI needs, loads the NAI images into a local registry and installs NAI. It records every change it makes so --uninstall can reverse exactly those changes.

3Get the script

Copy nai-on-openshift.sh (full source in section 11) to the host and make it executable. On the lab host it is already in place:

cd /shared_storage/nutanix
chmod +x nai-on-openshift.sh
sudo ./nai-on-openshift.sh --check      # read-only: OS, CPU, memory, disks, NVIDIA GPUs
sudo ./nai-on-openshift.sh --help

4Run it: VM example

tmux new -s nai 'sudo /shared_storage/nutanix/nai-on-openshift.sh'
# after a disconnect:
tmux attach -t nai

6Track progress

Every stage writes to one log. Watching it does not affect the install; Ctrl+C only stops watching.

sudo tail -f /var/lib/nai-ocp/run.log            # live log of every stage
sudo /shared_storage/nutanix/nai-on-openshift.sh --status   # finished stages, recorded changes, VM state
sudo ls /var/lib/nai-ocp/done/nai && echo "INSTALL COMPLETE"

Once OpenShift is up, check it directly. This host's sudo does not pass environment variables, so give the kubeconfig as a flag:

OC="sudo /shared_storage/nai-ocp-data/work/bin/oc --kubeconfig /shared_storage/nai-ocp-data/work/install/auth/kubeconfig"
$OC get clusterversion        # "Cluster version is 4.22.17" when OpenShift is done
$OC get co                    # every cluster operator AVAILABLE=True
$OC get nodes
$OC get pods -n nvidia-gpu-operator          # driver build for the CoreOS kernel
$OC get pods -n nai-system                   # NAI services

The install is finished when the log ends with the ready block (see section 8). If a stage fails, the log ends with a red ERROR line naming the stage; fix the cause and run the script again to continue from there.

Open the consoles from a workstation

The VM network (172.20.130.0/24) is private to the host, and the host resolves the cluster names. Tunnel through the host with SSH and point a separate browser profile at the tunnel:

ssh -D 1080 -N nutanix@<host-ip>
# Windows, in a second terminal:
"C:\Program Files\Google\Chrome\Application\chrome.exe" --user-data-dir=%TEMP%\nai-chrome --proxy-server="socks5://127.0.0.1:1080" https://nai.apps.sno.nai.lab/nai

The certificates are self-signed; accept the browser warning. After the first NAI login, change the password and apply the NAI licence.

    f=$WORK/${v#*:}; v=${v%%:*}; b=${v}_BYTES
    [[ ${!v} =~ ^https?:// ]] || continue
    [ -s "$f" ] && { ok "$(basename "$f") already downloaded"; continue; }
    echo "  downloading $(basename "${!v%%\?*}") ($(human "${!b:-0}")) to $f" | tee -a "$TLOG"
    download "${!v}" "$f" || die "download failed; re-run the script to resume (a new link may be needed if it expired)"
    ok "$(basename "$f") downloaded"
  done
  { tar -tf "$WORK/nai-images.tar" 2>/dev/null || true; } | grep -qm1 'index.json' || [[ ! $NAI_TAR_SRC =~ ^https?:// ]] \
    || die "the image bundle is not a valid NAI OCI bundle (index.json missing)"
  ok "NAI bundle and charts ready"
}

# ---------------------------------------------------------------- 1. questions (all asked up front)
host_inventory() {
  local cores threads nodes
  threads=$(nproc --all); cores=$(lscpu -p=SOCKET,CORE | grep -v '^#' | sort -u | wc -l)
  nodes=$(lscpu -p=NODE | grep -v '^#' | sort -u | wc -l)
  echo "  CPU     : $(lscpu | awk -F: '/Model name/{gsub(/^ +/,"",$2);print $2; exit}'), $cores cores / $threads threads, $nodes NUMA node(s)"
  echo "  Memory  : $(free -g | awk '/Mem:/{print $2" GB total, "$7" GB available"}')"
  echo "  Storage : most free space"
  df -BG --output=avail,target -x tmpfs -x devtmpfs -x overlay -x squashfs -x efivarfs 2>/dev/null | tail -n +2 | sort -rn | head -3 \
    | awk '{printf "            %7s free  %s\n", $1, $2}'
}

list_gpus() {   # numbered list of NVIDIA GPUs with memory, NUMA node, driver and whether the host is using them
  GPUS=($(nvidia_gpus)); local i=0 g mem note smi=""
  [ ${#GPUS[@]} = 0 ] && { echo "  GPUs    : no NVIDIA GPU in this host - the VM runs NAI on CPU"; return; }
  command -v nvidia-smi >/dev/null && smi=$(nvidia-smi --query-gpu=pci.bus_id,memory.total --format=csv,noheader 2>/dev/null || true)
  echo "  NVIDIA GPUs:"
  for g in "${GPUS[@]}"; do
    i=$((i + 1)); note=""
    mem=$(echo "$smi" | grep -i "${g#*:}," | awk -F', ' '{print $2}' || true)
    [ "$(cat /sys/bus/pci/devices/$g/boot_vga 2>/dev/null)" = 1 ] && note=" [drives the host display]"
    [ "$(drv "$g")" = vfio-pci ] && note=" [already reserved for passthrough]"
    printf "     %d) %s  %s  %s NUMA %s  driver %s%s\n" "$i" "$g" "$(gpu_name "$g")" "${mem:+$mem, }" \
      "$(cat /sys/bus/pci/devices/$g/numa_node)" "$(drv "$g")" "$note"
  done
}

gpu_group_ok() {   # the card's IOMMU group may hold only its own functions (and PCI bridges)
  iommu_on || return 0
  local grp d; grp=$(readlink -f "/sys/bus/pci/devices/$1/iommu_group")/devices
  for d in "$grp"/*; do d=$(basename "$d")
    [ "${d%.*}" = "${1%.*}" ] && continue
    [[ $(cat /sys/bus/pci/devices/$d/class) == 0x0604* ]] && continue
    echo "   $1 shares its IOMMU group with $d ($(lspci -s "$d" | cut -d' ' -f2-)): it cannot be passed through safely" >/dev/tty
    return 1
  done
}

is_pull_secret() { python3 -c "import json,sys;assert 'auths' in json.load(open(sys.argv[1]))" "$1" 2>/dev/null; }

ask_token() {   # Red Hat credential: API token (-> Red Hat console / Assisted Installer) or pull secret (-> agent-based)
  if [ "${INSTALL_METHOD:-}" = agent ] && is_pull_secret "$STATE/pull-secret.json"; then ok "pull secret already stored"; return; fi
  if [ "${INSTALL_METHOD:-}" = assisted ] && [ -s "$STATE/ocm-token" ] && ocm GET /api/accounts_mgmt/v1/current_account >/dev/null 2>&1; then
    ok "Red Hat token already stored"
  else
    echo; echo "${c_b}Red Hat credential${c_0} - paste either one:"
    echo "   - OpenShift API token  https://console.redhat.com/openshift/token"
    echo "       installs through the Red Hat console (Assisted Installer); the cluster is managed from your Red Hat account"
    echo "   - pull secret          https://console.redhat.com/openshift/install/pull-secret  ('Copy pull secret')"
    echo "       installs locally with the agent-based installer (the 'Local Agent-based' flow); the cluster still reports"
    echo "       to your Red Hat account"
    local t n=0 user err f=$STATE/cred.tmp
    while :; do
      t=$(ask_secret "   Paste the token or the pull secret (input hidden), or press Enter to give a file path")
      [ -z "$t" ] && { t=$(ask "   Path to the token or pull-secret file"); [ -f "$t" ] && t=$(cat "$t") || t=""; }
      ( umask 077; printf '%s' "$t" > "$f" ); t=""
      if is_pull_secret "$f"; then
        mv "$f" "$STATE/pull-secret.json"; INSTALL_METHOD=agent; save INSTALL_METHOD agent
        ok "pull secret accepted (stored mode 600, never printed): OpenShift is installed with the agent-based installer"
        return
      fi
      if grep -q '^{' "$f"; then err="that is JSON but not a pull secret (no \"auths\")"
      else
        mv "$f" "$STATE/ocm-token"; rm -f "$STATE/ocm-access.json"
        user=$(ocm GET /api/accounts_mgmt/v1/current_account 2>"$STATE/ocm.err" | jget username) || true
        [ -n "$user" ] && break
        err=$(tail -1 "$STATE/ocm.err" | cut -c1-160); rm -f "$STATE/ocm-token"
      fi
      rm -f "$f" "$STATE/ocm.err"; n=$((n + 1)); [ $n -ge 3 ] && die "no usable Red Hat credential ($err)"
      echo "   not accepted: ${err:-unknown error} - try again" >/dev/tty
    done
    rm -f "$STATE/ocm.err"; INSTALL_METHOD=assisted; save INSTALL_METHOD assisted
    ok "token accepted: Red Hat account $user (stored mode 600, never printed): OpenShift is installed through the Red Hat console"
  fi
  ( umask 077; ocm POST /api/accounts_mgmt/v1/access_token > "$STATE/pull-secret.json" )
  is_pull_secret "$STATE/pull-secret.json" || die "could not fetch the pull secret with this token"
  ok "pull secret fetched from the Red Hat console"
}

vm_questions() {
  echo; echo "${c_b}This host ($(hostname))${c_0}"; host_inventory; list_gpus
  local threads avail sel def g i bad
  threads=$(nproc --all); avail=$(free -g | awk '/Mem:/{print $7}')

  echo; echo "${c_b}GPU${c_0}: NAI runs endpoints on NVIDIA GPUs or on CPU. A passed-through GPU is used only by the VM"
  echo "     (the host loses it until --uninstall), and needs one reboot (asked first)."
  GPU_BDFS=""
  if [ ${#GPUS[@]} -gt 0 ]; then
    def=1; for i in "${!GPUS[@]}"; do [ "$(cat /sys/bus/pci/devices/${GPUS[$i]}/boot_vga 2>/dev/null)" = 1 ] || { def=$((i + 1)); break; }; done
    while :; do
      sel=$(ask "   GPUs for the VM: number(s) e.g. 1 or 1,2 - 'all' - or 'none' for CPU-only" "$def"); GPU_BDFS=""; bad=0
      case $sel in
        none|NONE|0) break ;;
        all|ALL) sel=$(seq -s, 1 ${#GPUS[@]}) ;;
      esac
      for i in ${sel//,/ }; do
        [[ $i =~ ^[0-9]+$ ]] && [ "$i" -ge 1 ] && [ "$i" -le ${#GPUS[@]} ] || { echo "   no GPU number $i" >/dev/tty; bad=1; continue; }
        g=${GPUS[$((i - 1))]}; [[ " $GPU_BDFS " == *" $g "* ]] && continue
        gpu_group_ok "$g" || { bad=1; continue; }
        if [ "$(cat /sys/bus/pci/devices/$g/boot_vga 2>/dev/null)" = 1 ]; then
          yesno "   GPU $i drives this host's display; the host loses it. Use it anyway" n || { bad=1; continue; }
        fi
        GPU_BDFS="${GPU_BDFS:+$GPU_BDFS }$g"
      done
      [ $bad = 0 ] && [ -n "$GPU_BDFS" ] && break
      [ -n "$GPU_BDFS" ] && yesno "   Continue with $GPU_BDFS only" y && break
    done
  fi
  save GPU_BDFS "$GPU_BDFS"
  [ -n "$GPU_BDFS" ] && ok "GPU passthrough: $GPU_BDFS" || ok "CPU-only: NAI endpoints run on the VM's CPUs (no GPU, no reboot)"

  echo; echo "${c_b}VM size${c_0}: NAI's platform services reserve about 19 cores; endpoints need the rest."
  local maxc=$((threads - 4)) dc dm maxm=$((avail - 16))
  if [ -n "$GPU_BDFS" ]; then dc=48; dm=128; else dc=64; dm=192; fi
  [ $dc -gt $maxc ] && dc=$maxc; [ $dm -gt $maxm ] && dm=$maxm
  [ $maxm -ge 48 ] || die "only $avail GB memory available: OpenShift + NAI need at least 64 GB for the VM"
  VM_VCPUS=$(ask_int "   vCPUs (host has $threads threads; 48+ recommended with GPU, 64+ CPU-only)" $dc 24 $maxc)
  VM_VCPUS=$(( (VM_VCPUS + 1) / 2 * 2 ))                                   # whole cores (2 threads each)
  [ $VM_VCPUS -lt 40 ] && warn "$VM_VCPUS vCPUs leaves little room for endpoints after NAI's ~19-core reservation"
  VM_RAM_GB=$(ask_int "   Memory in GB ($avail GB available; 128+ recommended with GPU, 192+ CPU-only)" $dm 48 $maxm)
  [ $VM_RAM_GB -lt 96 ] && warn "$VM_RAM_GB GB: NAI needs ~17 GB per small model on top of the platform (NAI-10014)"

  echo; echo "${c_b}Storage${c_0}: two VM disks (CoreOS + OpenShift; LVM storage for NAI's databases and model cache), plus"
  echo "   the NAI bundle (~60 GB unpacked), the image registry and the NFS model share."
  OS_DISK_GB=$(ask_int "   OS disk GB" 200 120 2000)
  DATA_DISK_GB=$(ask_int "   Data disk GB (LVM storage inside OpenShift)" 500 100 20000)
  ask_storage_dir "VM disks, NAI bundle, registry and NFS model share" $((OS_DISK_GB + DATA_DISK_GB + 300))
  save VM_VCPUS "$VM_VCPUS"; save VM_RAM_GB "$VM_RAM_GB"; save OS_DISK_GB "$OS_DISK_GB"; save DATA_DISK_GB "$DATA_DISK_GB"
}

  if ! rs true 2>/dev/null; then
    local p n=0 ap=$STATE/askpass
    printf '#!/bin/sh\nprintf "%%s\\n" "$NAI_SSHPASS"\n' > "$ap"; chmod 700 "$ap"
    while :; do
      p=$(ask_secret "   root password of $RHOST (hidden; used once to install an SSH key)")

  fi
  ok "root SSH to $RHOST works (key-based; the password is not stored)"

  local info; info=$(rs 'set +e; . /etc/os-release; echo "OS=$ID"; echo "VER=$VERSION_ID"; echo "NAME=$PRETTY_NAME"

  echo "   OS      : $NAME (kernel $KERNEL)"
  echo "   CPU     : $THREADS threads, virtualization flags $([ "${VIRT:-0}" -gt 0 ] && echo present || echo MISSING)"
  echo "   Memory  : ${MEM} GB available;  largest free space: $FREE"
  echo "   GPUs    : $([ "$LSPCI" = yes ] && echo "${GPUS:-0} NVIDIA device(s)" || echo 'unknown (pciutils missing; installed next)')"
  local maj=${VER%%.*} ok_os=no
  case $OS in
    ubuntu) [[ ${VER/./} -ge 2204 ]] && ok_os=yes ;;
    debian) [ "${maj:-0}" -ge 12 ] && ok_os=yes ;;
    rhel|rocky|almalinux|centos) [ "${maj:-0}" -ge 8 ] && ok_os=yes ;;
    fedora) [ "${maj:-0}" -ge 38 ] && ok_os=yes ;;
  esac
  [ $ok_os = yes ] || die "$NAME is not supported (Ubuntu 22.04+, Debian 12+, RHEL/Rocky/Alma/CentOS Stream 8+, Fedora 38+)"
  [ "${VIRT:-0}" -gt 0 ] || die "$RHOST has no CPU virtualization (enable SVM/VT-x in its BIOS)"
  [ "${MEM:-0}" -ge 80 ] || die "$RHOST has only ${MEM} GB memory available (OpenShift + NAI need 64 GB+ for the VM)"
  [ "$PKG" = dnf ] && [ "${REPOS:-0}" = 0 ] && die "$RHOST has no enabled dnf repositories (register it: subscription-manager register)"
  ok "$NAME is supported for the VM deployment"
  local need=""; [ "$PY" = yes ] || need="python3"; [ "$LSPCI" = yes ] || need="$need pciutils"
  if [ -n "$need" ]; then
    echo "   installing on $RHOST (needed to run the setup there): $need"
    rs "DEBIAN_FRONTEND=noninteractive; command -v apt-get >/dev/null && { apt-get update -qq; apt-get install -y -qq $need; } || dnf install -y -q $need" >/dev/null \
      || die "could not install $need on $RHOST"
    for k in $need; do rec "REMOTEPKG $k"; done
  fi
  echo "   VM size and GPUs are chosen next, on $RHOST itself (its inventory is shown there)."
  DATA=$STATE/data; save DATA "$DATA"
}

    access (the Assisted Installer pulls OpenShift from Red Hat), and a free IP address for the node.
EOF

  BMC_USER=$u; save BMC_USER "$BMC_USER"
  RF_SYSTEM=""; RF_VMEDIA=""
  if [ "$code" = 200 ]; then

      code=$(rf_code POST "$mgr/Actions/Oem/AMIVirtualMedia.EnableRMedia" '{"RMediaState":"Enable"}')
      [[ $code == 2* ]] || { warn "the BMC refused to enable remote media (HTTP $code)"; break; }
      rec "AMIRMEDIA $mgr"; sleep 10
    done
    sys=$(rf "$RF_SYSTEM")
    ok "BMC login ok: $(echo "$sys" | jget Manufacturer) $(echo "$sys" | jget Model), serial $(echo "$sys" | jget SerialNumber), power $(echo "$sys" | jget PowerState)"
    echo "   CPUs: $(echo "$sys" | jget ProcessorSummary/Count) x $(echo "$sys" | jget ProcessorSummary/Model)   memory: $(echo "$sys" | jget MemorySummary/TotalSystemMemoryGiB) GiB"
    [ -n "$RF_VMEDIA" ] && ok "virtual CD available through the BMC (mounted automatically)" \
      || warn "no virtual CD over the BMC API: you mount the ISO in the BMC web console when asked"
  fi
  save RF_SYSTEM "$RF_SYSTEM"; save RF_VMEDIA "$RF_VMEDIA"

  echo; echo "${c_b}Node network${c_0}"
  local nics=() e mac i=0 sel j
  if [ -n "$RF_SYSTEM" ]; then
    for e in $(rf "$RF_SYSTEM/EthernetInterfaces" | members); do

    done

  pfx=$(ip -o -4 addr show dev "${dev:-lo}" 2>/dev/null | awk '{print $4}' | head -1 | cut -d/ -f2)

  echo "   Address assignment: 'static' writes the address into the ISO; 'dhcp' needs a DHCP reservation $NODE_MAC -> $NODE_IP"
  NET_MODE=$(ask "   static or dhcp" static); [[ $NET_MODE =~ ^(static|dhcp)$ ]] || die "answer static or dhcp"

  echo; echo "${c_b}DNS${c_0}: OpenShift needs api.<cluster>.<domain>, api-int.<cluster>.<domain> and *.apps.<cluster>.<domain> -> $NODE_IP"
  local up; up=$(awk '/^nameserver/ && $2 !~ /^127\./ {print $2; exit}' /run/systemd/resolve/resolv.conf /etc/resolv.conf 2>/dev/null || true)
  if yesno "   Do these DNS records already exist (or will you create them now)" n; then
    HOST_DNS=no
    CLUSTER_NAME=$(ask "   Cluster name" "$CLUSTER_NAME"); BASE_DOMAIN=$(ask "   Base domain" "$BASE_DOMAIN")
    NODE_DNS=$(ask "   DNS server the node uses" "$up"); valid_ip "$NODE_DNS" || die "not an IPv4 address: $NODE_DNS"

  else

    UPSTREAM_DNS=$(ask "   Upstream DNS for all other names" "$up"); valid_ip "$UPSTREAM_DNS" || die "not an IPv4 address: $UPSTREAM_DNS"
    save UPSTREAM_DNS "$UPSTREAM_DNS"
    [ "$NET_MODE" = dhcp ] && { warn "with DHCP the node takes DNS from your DHCP server; switching to static so it uses this host's DNS"; NET_MODE=static; }
    ok "this host ($NODE_DNS) answers the cluster names and forwards the rest to $UPSTREAM_DNS"
  fi

  echo; echo "${c_b}Server disks${c_0} (Linux names as the installer sees them, e.g. /dev/sda, /dev/nvme0n1)"
  INSTALL_DISK=$(ask "   Install disk for CoreOS/OpenShift - ERASED (Enter = the installer's choice, shown before installing)" "")
  DATA_DEVICE=$(ask "   Second disk for OpenShift local storage (LVM for NAI databases and model cache) - ERASED")
  [[ $DATA_DEVICE == /dev/* ]] || die "a data disk such as /dev/nvme1n1 is required"
  [ "$DATA_DEVICE" != "$INSTALL_DISK" ] || die "the data disk must differ from the install disk"
  echo; echo "${c_b}GPU${c_0}: NAI runs endpoints on NVIDIA GPUs or on CPU."
  yesno "   Does the server have NVIDIA GPUs for NAI (y installs the NVIDIA GPU Operator, n = CPU-only)" y && BM_GPU=yes || BM_GPU=no
  echo; echo "${c_b}This host${c_0} keeps the NAI bundle (~60 GB unpacked), the image registry and the NFS model share."
  ask_storage_dir "NAI bundle, registry and NFS model share" 300
  local v; for v in NODE_MAC NODE_IP NODE_PREFIX NODE_GW NET_MODE HOST_DNS NODE_DNS CLUSTER_NAME BASE_DOMAIN INSTALL_DISK DATA_DEVICE BM_GPU; do save $v "${!v}"; done
}

apt_install() {   # host apt may be locked to an offline repo (NKP does this): fall back to a private Ubuntu
  local p miss=0   # archive source under $STATE/apt - /etc/apt is never modified
  export DEBIAN_FRONTEND=noninteractive
  apt-get update -qq >/dev/null 2>&1 || true
  for p in "$@"; do apt-cache policy "$p" 2>/dev/null | grep -q 'Candidate: [0-9]' || miss=1; done
  if [ $miss = 0 ]; then apt-get install -y -qq --no-install-recommends "$@"; return; fi
  local d=$STATE/apt code; code=$(. /etc/os-release; echo "${VERSION_CODENAME:-$UBUNTU_CODENAME}")
  [ -n "$code" ] || die "cannot tell the Ubuntu release; install $* manually and re-run"
  mkdir -p "$d/lists/partial" "$d/archives/partial"; id _apt >/dev/null 2>&1 && chown -R _apt "$d/lists/partial" "$d/archives/partial"
  { echo "deb http://archive.ubuntu.com/ubuntu $code main universe restricted multiverse"
    echo "deb http://archive.ubuntu.com/ubuntu $code-updates main universe restricted multiverse"
    echo "deb http://security.ubuntu.com/ubuntu $code-security main universe restricted multiverse"; } > "$d/sources.list"
  local o=(-o Dir::Etc::SourceList="$d/sources.list" -o Dir::Etc::SourceParts=- -o Dir::State::Lists="$d/lists"
           -o Dir::Cache::Archives="$d/archives")
  echo "  host apt has no Ubuntu archive configured (offline repo only); using a private source" | tee -a "$TLOG"
  apt-get "${o[@]}" update -qq || die "cannot reach archive.ubuntu.com"
  apt-get "${o[@]}" install -y -qq --no-install-recommends --no-upgrade "$@"
}

host_packages() {
  local apt=(curl skopeo podman) dnf=(curl skopeo podman) need=0 b
  if [ $MODE = vm ]; then
    apt+=(qemu-system-x86 qemu-utils libvirt-daemon-system libvirt-clients virtinst ovmf dnsmasq-base)
    dnf+=(qemu-kvm libvirt virt-install edk2-ovmf)
    for b in virt-install virsh qemu-img; do command -v $b >/dev/null || need=1; done
    ls /usr/share/OVMF/OVMF_CODE*.fd /usr/share/edk2/ovmf/OVMF_CODE*.fd /usr/share/edk2/ovmf/OVMF_CODE*.qcow2 >/dev/null 2>&1 || need=1
  else
    apt+=(ipmitool); dnf+=(ipmitool); command -v ipmitool >/dev/null || need=1
    [ "$HOST_DNS" = yes ] && { apt+=(dnsmasq-base); dnf+=(dnsmasq); command -v dnsmasq >/dev/null || need=1; }
    [ "$INSTALL_METHOD" = agent ] && [ "$NET_MODE" = static ] && { apt+=(nmstate); dnf+=(nmstate); command -v nmstatectl >/dev/null || need=1; }
  fi
  for b in curl skopeo; do command -v $b >/dev/null || need=1; done
  command -v podman >/dev/null || command -v docker >/dev/null || need=1
  if [ $need = 1 ]; then
    pkg_list > "$STATE/pkgs.before"
    case $(pkg_mgr) in
      apt) apt_install "${apt[@]}" ;;
      dnf) dnf install -y -q "${dnf[@]}" ;;
      *)   die "no apt/dnf: install ${apt[*]} manually" ;;
    esac
    pkg_new "$STATE/pkgs.before" | while read -r p; do rec "PKG $p"; done
    ok "installed $(grep -c '^PKG ' "$MANIFEST") packages (recorded for uninstall)"
  else
    ok "required packages already present (nothing installed)"
  fi
  if [ $MODE = vm ]; then
    systemctl enable --now libvirtd >/dev/null 2>&1 || systemctl enable --now virtqemud >/dev/null 2>&1 || true
    if virsh net-info default >/dev/null 2>&1; then   # libvirt's default net can collide with container networks
      virsh net-destroy default >/dev/null 2>&1 || true; virsh net-autostart default --disable >/dev/null 2>&1 || true
    fi
  else
    if ipmi chassis power status >/dev/null 2>&1; then ok "IPMI over LAN works: $(ipmi chassis power status)"
    elif [ -n "$RF_SYSTEM" ]; then warn "IPMI over LAN refused (disabled on the BMC?); power and boot go through the BMC's Redfish API"
    else die "IPMI over LAN to $BMC_HOST failed and the BMC has no Redfish API: enable 'IPMI over LAN' on the BMC and re-run"; fi
  fi
}

gpus_reserved() { local g f; for g in $GPU_BDFS; do for f in $(gpu_functions "$g"); do [ "$(drv "$f")" = vfio-pci ] || return 1; done; done; }

host_prep() {   # vm: KVM; with GPUs also IOMMU on + GPUs reserved for vfio - one reboot, only with consent
  [ -e /dev/kvm ] || modprobe kvm_amd 2>/dev/null || modprobe kvm_intel 2>/dev/null || true
  [ -e /dev/kvm ] || die "hardware virtualization is off: enable it in the BIOS (AMD: SVM Mode, Intel: VT-x), reboot, re-run"
  ok "KVM available"
  [ -z "$GPU_BDFS" ] && { ok "CPU-only VM: no GPU passthrough, no reboot"; return; }
  local why=() g f p
  if ! iommu_on; then
    p=$(grep -q AuthenticAMD /proc/cpuinfo && echo "amd_iommu=on iommu=pt" || echo "intel_iommu=on iommu=pt")
    if command -v grubby >/dev/null; then
      grubby --info=DEFAULT | grep -q "${p%% *}" || { grubby --update-kernel=ALL --args="$p"; rec "GRUBBY $p"; }
    elif [ ! -f /etc/default/grub.d/90-nai-ocp-iommu.cfg ]; then
      echo "GRUB_CMDLINE_LINUX_DEFAULT=\"\$GRUB_CMDLINE_LINUX_DEFAULT $p\"" > /etc/default/grub.d/90-nai-ocp-iommu.cfg
      rec "GRUBFILE /etc/default/grub.d/90-nai-ocp-iommu.cfg"; update-grub >/dev/null 2>&1
    fi
    why+=("turn on the IOMMU")
  fi
  for g in $GPU_BDFS; do for f in $(gpu_functions "$g"); do   # tagged but driverless (vfio-pci loaded before the tag): bind now
    [ -z "$(drv "$f")" ] && [ "$(cat /sys/bus/pci/devices/$f/driver_override 2>/dev/null)" = vfio-pci ] \
      && { modprobe vfio-pci; echo "$f" > /sys/bus/pci/drivers_probe 2>/dev/null || true; }
  done; done
  if gpus_reserved; then :
  elif [ -f "$DONE/reboot-gpu" ] && [ "$(cat "$DONE/reboot-gpu")" != "$(cat /proc/sys/kernel/random/boot_id)" ]; then   # rebooted once already: never again
    for g in $GPU_BDFS; do for f in $(gpu_functions "$g"); do echo "  $f driver: $(drv "$f") override: $(cat /sys/bus/pci/devices/$f/driver_override 2>/dev/null)"; done; done
    die "the GPU reservation did not take effect after the reboot (see drivers above); not rebooting again"
  else
    # driver_override tags the card by PCI address; RUN re-probes so vfio-pci claims it even if it loaded first
    { echo "# nai-on-openshift: GPUs reserved for VM passthrough: $GPU_BDFS"
      for g in $GPU_BDFS; do for f in $(gpu_functions "$g"); do
        echo "ACTION==\"add\", SUBSYSTEM==\"pci\", KERNEL==\"$f\", ATTR{driver_override}=\"vfio-pci\", RUN+=\"/sbin/modprobe -b vfio-pci\", RUN+=\"/bin/sh -c 'echo %k > /sys/bus/pci/drivers_probe'\""; done; done
    } > /etc/udev/rules.d/90-nai-ocp-vfio.rules
    printf 'softdep nvidia pre: vfio-pci\nsoftdep nouveau pre: vfio-pci\nsoftdep snd_hda_intel pre: vfio-pci\n' > /etc/modprobe.d/90-nai-ocp-vfio.conf
    echo vfio-pci > /etc/modules-load.d/90-nai-ocp-vfio.conf
    rec "FILE /etc/udev/rules.d/90-nai-ocp-vfio.rules"; rec "FILE /etc/modprobe.d/90-nai-ocp-vfio.conf"
    rec "FILE /etc/modules-load.d/90-nai-ocp-vfio.conf"; rec "INITRAMFS"
    if command -v update-initramfs >/dev/null; then update-initramfs -u -k "$(uname -r)" >/dev/null; else dracut -f; fi
    cat /proc/sys/kernel/random/boot_id > "$DONE/reboot-gpu"   # remembers which boot asked for the reboot
    why+=("reserve GPU(s) $GPU_BDFS for the VM (the host stops using them)")
  fi
  [ ${#why[@]} = 0 ] && { rm -f "$STATE/need-reboot"; ok "IOMMU active; GPU(s) $GPU_BDFS reserved for the VM"; return; }
  local msg; msg=$(printf '%s; ' "${why[@]}"); reboot_ask "${msg%; }"
}

fw_allow() {   # port proto: open the host firewall to the cluster, if one is active (recorded)
  if command -v ufw >/dev/null && ufw status 2>/dev/null | grep -q 'Status: active'; then
    ufw allow from "$CLIENT_NET" to any port "$1" proto "$2" >/dev/null; rec "UFW from $CLIENT_NET to any port $1 proto $2"
  elif command -v firewall-cmd >/dev/null && firewall-cmd --state >/dev/null 2>&1; then
    local z; z=$(firewall-cmd --get-default-zone)
    [ "$MODE" = vm ] && firewall-cmd --get-zones | grep -qw libvirt && z=libvirt   # VM traffic arrives in libvirt's zone
    firewall-cmd -q --permanent --zone="$z" --add-port="$1/$2"; firewall-cmd -q --reload; rec "FIREWALLD $z $1/$2"
  fi
}

vm_network() {
  if [ -z "${NET_PREFIX:-}" ]; then
    local x; for x in 130 131 132 140 150; do ip route | grep -q "172.20.$x\." || { NET_PREFIX=172.20.$x; break; }; done
    [ -n "${NET_PREFIX:-}" ] || die "no free 172.20.x.0/24 network"; save NET_PREFIX "$NET_PREFIX"
  fi
  NODE_IP=$NET_PREFIX.10; SVC_IP=$NET_PREFIX.1; CLIENT_NET=$NET_PREFIX.0/24
  MACHINE_CIDR=$NET_PREFIX.0/24; save NODE_IP "$NODE_IP"; save SVC_IP "$SVC_IP"; save CLIENT_NET "$CLIENT_NET"; save MACHINE_CIDR "$MACHINE_CIDR"
  if ! virsh net-info "$NET_NAME" >/dev/null 2>&1; then
    cat > "$WORK/net.xml" <<EOF
<network xmlns:dnsmasq='http://libvirt.org/schemas/network/dnsmasq/1.0'>
  <name>$NET_NAME</name>
  <forward mode='nat'/>
  <bridge name='$NET_BRIDGE' stp='on' delay='0'/>
  <domain name='$BASE_DOMAIN' localOnly='yes'/>
  <dns><host ip='$NODE_IP'><hostname>api.$CLUSTER_NAME.$BASE_DOMAIN</hostname><hostname>api-int.$CLUSTER_NAME.$BASE_DOMAIN</hostname></host></dns>
  <ip address='$NET_PREFIX.1' netmask='255.255.255.0'>
    <dhcp><range start='$NET_PREFIX.100' end='$NET_PREFIX.200'/><host mac='$VM_MAC' name='$CLUSTER_NAME' ip='$NODE_IP'/></dhcp>
  </ip>
  <dnsmasq:options><dnsmasq:option value='address=/apps.$CLUSTER_NAME.$BASE_DOMAIN/$NODE_IP'/></dnsmasq:options>
</network>
EOF
    virsh net-define "$WORK/net.xml" >/dev/null; virsh net-autostart "$NET_NAME" >/dev/null; virsh net-start "$NET_NAME" >/dev/null
    rec "NET $NET_NAME"
  fi
  if command -v resolvectl >/dev/null && systemctl is-active -q systemd-resolved; then
    mkdir -p /etc/libvirt/hooks
    [ -f /etc/libvirt/hooks/network ] && ! grep -q nai-on-openshift /etc/libvirt/hooks/network && die "/etc/libvirt/hooks/network exists and is not ours"
    printf '#!/bin/sh\n# nai-on-openshift\n[ "$1" = "%s" ] && [ "$2" = started ] && { resolvectl dns %s %s; resolvectl domain %s "~%s"; }\nexit 0\n' \
      "$NET_NAME" "$NET_BRIDGE" "$NET_PREFIX.1" "$NET_BRIDGE" "$BASE_DOMAIN" > /etc/libvirt/hooks/network
    chmod 755 /etc/libvirt/hooks/network; rec "FILE /etc/libvirt/hooks/network"
    resolvectl dns "$NET_BRIDGE" "$NET_PREFIX.1"; resolvectl domain "$NET_BRIDGE" "~$BASE_DOMAIN"
  else
    hosts_entries
  fi
  ok "VM network $NET_PREFIX.0/24; cluster names resolve to $NODE_IP"
}

bm_network() {   # bare metal: this host serves registry/NFS (and DNS) to the node
  SVC_IP=$(host_ip "$NODE_IP"); CLIENT_NET=$NODE_IP/32
  [ -n "$SVC_IP" ] || die "no route from this host to $NODE_IP"
  MACHINE_CIDR=$(python3 -c "import ipaddress,sys;print(ipaddress.ip_network(sys.argv[1],strict=False))" "$NODE_IP/$NODE_PREFIX")
  save SVC_IP "$SVC_IP"; save CLIENT_NET "$CLIENT_NET"; save MACHINE_CIDR "$MACHINE_CIDR"
  if [ "$HOST_DNS" = yes ]; then
    ss -lunH "sport = :53" 2>/dev/null | grep -qE "($SVC_IP|0\.0\.0\.0|\*):53 " && die "port 53 on $SVC_IP is taken; re-run and say the DNS records exist"
    local d=$CLUSTER_NAME.$BASE_DOMAIN
    cat > "$DNS_UNIT" <<EOF
[Unit]
Description=nai-on-openshift: DNS for the OpenShift cluster $d
After=network-online.target
Wants=network-online.target
[Service]
ExecStart=$(command -v dnsmasq) -k --user=nobody --group=$(getent group nogroup >/dev/null && echo nogroup || echo nobody) --bind-interfaces --listen-address=$SVC_IP --no-resolv --no-hosts --server=$UPSTREAM_DNS --host-record=api.$d,$NODE_IP --host-record=api-int.$d,$NODE_IP --address=/apps.$d/$NODE_IP
Restart=always
[Install]
WantedBy=multi-user.target
EOF
    rec "FILE $DNS_UNIT"; rec "SERVICE nai-ocp-dns"
    systemctl daemon-reload; systemctl enable --now nai-ocp-dns >/dev/null 2>&1 || die "DNS service failed (journalctl -u nai-ocp-dns)"
    fw_allow 53 udp; fw_allow 53 tcp
    ok "DNS for $d on $SVC_IP (other names forwarded to $UPSTREAM_DNS)"
  fi
  getent hosts "api.$CLUSTER_NAME.$BASE_DOMAIN" | grep -q "^$NODE_IP " || hosts_entries
  ok "node $NODE_IP; this host serves the cluster from $SVC_IP"
}

    download "$url" "$WORK/discovery.iso" || die "discovery ISO download failed; re-run to resume"
  fi
  ok "discovery ISO $(human "$(stat -c %s "$WORK/discovery.iso")")"
}

cpuset() {   # $2 vCPUs as whole cores (+SMT siblings), NUMA node $1 first, leaving the first core to the host
  python3 - "$1" "$2" <<'EOF'
import subprocess, sys
node, want = int(sys.argv[1]), int(sys.argv[2])
cores = {}
for l in subprocess.check_output(["lscpu", "-p=CPU,CORE,NODE"], text=True).splitlines():
    if l.startswith("#"): continue
    cpu, core, n = l.split(",")
    cores.setdefault((int(n or 0), int(core)), []).append(int(cpu))
keys = sorted(cores)[1:]
pref = [k for k in keys if node < 0 or k[0] == node]
out = []
for k in pref + [k for k in keys if k not in pref]:
    if len(out) >= want: break
    out += cores[k]
print(",".join(map(str, out[:want])))
EOF
}

vm_create() {
  virsh dominfo "$VM_NAME" >/dev/null 2>&1 && { ok "VM exists"; return; }
  local disks=$DATA/vm node=-1 hostdev=() g f os=rhel9.4
  mkdir -p "$disks"; cp "$WORK/discovery.iso" "$disks/discovery.iso"
  for g in $GPU_BDFS; do
    [ $node = -1 ] && node=$(cat /sys/bus/pci/devices/$g/numa_node)
    for f in $(gpu_functions "$g"); do [ "$(drv "$f")" = vfio-pci ] || die "$f is not reserved for passthrough (reboot needed?)"; hostdev+=(--hostdev "$f"); done
  done
  local avail; avail=$(free -g | awk '/Mem:/{print $7}')
  [ "$avail" -ge $((VM_RAM_GB + 8)) ] || die "only $avail GB memory free now; the VM needs $VM_RAM_GB GB (free memory, or --uninstall and answer again)"
  local cpus numa=(); cpus=$(cpuset "$node" "$VM_VCPUS")
  [ "$node" -ge 0 ] && numa=(--numatune "$node,mode=preferred")
  virt-install --osinfo list 2>/dev/null | grep -qw rhel9.4 || os=linux2022
  # plain UEFI firmware without Secure Boot, named explicitly: auto-selection can pick the AMD-SEV/TDX build, which
  # Ubuntu's AppArmor helper rejects ("skipped restricted file"), and Secure Boot blocks the in-cluster NVIDIA driver
  local fw_code="" fw_vars="" c
  for c in /usr/share/OVMF/OVMF_CODE_4M.fd /usr/share/OVMF/OVMF_CODE.fd /usr/share/edk2/ovmf/OVMF_CODE.fd /usr/share/edk2/x64/OVMF_CODE.4m.fd /usr/share/edk2/x64/OVMF_CODE.fd; do
    [ -f "$c" ] && [ -f "${c/CODE/VARS}" ] && { fw_code=$c; fw_vars=${c/CODE/VARS}; break; }
  done
  [ -n "$fw_code" ] || die "no non-Secure-Boot OVMF firmware (OVMF_CODE + OVMF_VARS) found on this host"
  log "creating VM $VM_NAME: $VM_VCPUS vCPU, $VM_RAM_GB GB, ${OS_DISK_GB}+${DATA_DISK_GB} GB disks, ${GPU_BDFS:-no GPU (CPU-only)}"
  virt-install --name "$VM_NAME" --osinfo "$os" \
    --boot "loader=$fw_code,loader.readonly=yes,loader.type=pflash,loader.secure=no,nvram.template=$fw_vars" \
    --cpu host-passthrough --vcpus "$VM_VCPUS,cpuset=$cpus" "${numa[@]}" --memory $((VM_RAM_GB * 1024)) \
    --disk "path=$disks/os.qcow2,size=$OS_DISK_GB,format=qcow2,bus=virtio,cache=none,io=native" \
    --disk "path=$disks/data.qcow2,size=$DATA_DISK_GB,format=qcow2,bus=virtio,cache=none,io=native" \
    --cdrom "$disks/discovery.iso" --network "network=$NET_NAME,mac=$VM_MAC,model=virtio" \
    "${hostdev[@]}" --graphics vnc,listen=127.0.0.1 --noautoconsole --autostart --wait 0 >/dev/null
  rec "VM $VM_NAME"
}

bm_boot() {   # serve the ISO over HTTP, attach it as virtual CD, boot the server from it once over IPMI
  local ip p=8088 dir=$WORK/iso-http url code body
  ip=$(host_ip "${BMC_HOST%%:*}"); [ -n "$ip" ] || ip=$SVC_IP
  while ! port_free $p; do p=$((p + 1)); done
  mkdir -p "$dir"; ln -f "$WORK/discovery.iso" "$dir/discovery.iso" 2>/dev/null || cp "$WORK/discovery.iso" "$dir/discovery.iso"
  systemctl stop nai-ocp-iso >/dev/null 2>&1 || true
  systemd-run -q --unit nai-ocp-iso --collect python3 -m http.server "$p" --bind "$ip" --directory "$dir"
  sleep 2; url=http://$ip:$p/discovery.iso
  python3 -c "import urllib.request,sys;urllib.request.urlopen(urllib.request.Request(sys.argv[1],method='HEAD'),timeout=10)" "$url" \
    || die "cannot serve the ISO at $url"
  CLIENT_NET=${BMC_HOST%%:*} fw_allow $p tcp
  if [ -n "$RF_VMEDIA" ]; then
    rf_code POST "$RF_VMEDIA/Actions/VirtualMedia.EjectMedia" >/dev/null || true
    code=000
    for body in "{\"Image\":\"$url\",\"Inserted\":true,\"WriteProtected\":true,\"TransferProtocolType\":\"HTTP\"}" \
                "{\"Image\":\"$url\",\"Inserted\":true,\"WriteProtected\":true}" "{\"Image\":\"$url\"}"; do
      code=$(rf_code POST "$RF_VMEDIA/Actions/VirtualMedia.InsertMedia" "$body"); [[ $code == 2* ]] && break
    done
    [[ $code == 2* ]] || code=$(rf_code PATCH "$RF_VMEDIA" "{\"Image\":\"$url\",\"Inserted\":true}")
    [[ $code == 2* ]] || die "BMC refused the virtual media (HTTP $code). Mount $url as virtual CD by hand, then re-run."
    rec "BMCMEDIA $RF_VMEDIA"; ok "ISO attached as virtual CD from $url"
  else
    [ $INTERACTIVE = 1 ] || die "mount $url as virtual CD in the BMC web console, then re-run this script interactively"
    echo "  ${c_b}Mount the ISO now${c_0}: in the BMC web console (https://${BMC_HOST%%:*}) open Remote Control / Virtual Media"
    echo "  and attach this URL (or download it and attach the file) as CD/DVD:  $url"
    ask "  Press Enter once it is attached" >/dev/null
  fi
  if ipmi chassis bootdev cdrom options=efiboot >/dev/null 2>&1; then
    ok "IPMI: next boot from CD (UEFI, once)"
    if ipmi chassis power status | grep -q 'is on'; then ipmi chassis power cycle >/dev/null; else ipmi chassis power on >/dev/null; fi
    ok "IPMI: server power-cycled into the discovery ISO; its disks are overwritten by the installer"
  else
    [ -n "$RF_SYSTEM" ] || die "IPMI boot-device command failed and the BMC has no Redfish API"
    code=$(rf_code PATCH "$RF_SYSTEM" '{"Boot":{"BootSourceOverrideTarget":"Cd","BootSourceOverrideEnabled":"Once","BootSourceOverrideMode":"UEFI"}}')
    [[ $code == 2* ]] || code=$(rf_code PATCH "$RF_SYSTEM" '{"Boot":{"BootSourceOverrideTarget":"Cd","BootSourceOverrideEnabled":"Once"}}')
    [[ $code == 2* ]] || die "BMC refused the one-time CD boot (HTTP $code)"
    if [ "$(rf "$RF_SYSTEM" | jget PowerState)" = On ]; then body=ForceRestart; else body=On; fi
    code=$(rf_code POST "$RF_SYSTEM/Actions/ComputerSystem.Reset" "{\"ResetType\":\"$body\"}")
    [[ $code == 2* ]] || die "BMC refused the power action $body (HTTP $code)"
    ok "Redfish: server booting the discovery ISO (power action $body)"
  fi
}

host_report() {   # failing validations of the node and the cluster, as the Red Hat console shows them
  python3 -c '
import json, sys
hosts, cl = json.loads(sys.argv[1] or "[]"), json.loads(sys.argv[2] or "{}")
def failing(v, prefix):
    for items in json.loads(v or "{}").values():
        for it in items:
            if it.get("status") == "failure": print("     - " + prefix + it.get("id", "") + ": " + it.get("message", "")[:140])
for h in hosts:
    print("   node " + (h.get("requested_hostname") or h.get("id", "")[:8]) + ": " + str(h.get("status")) + " - " + (h.get("status_info") or "")[:110])
    failing(h.get("validations_info"), "")
failing(cl.get("validations_info"), "cluster ")' "$1" "$2"
}

install_wait() {
  local hosts cl st hid want disk path i keeper="" last="" pct info
  if [ $MODE = vm ]; then   # the VM powers off after CoreOS is written: start it again (it then boots from disk)
    ( while [ ! -f "$WORK/install-finished" ]; do [ "$(virsh domstate "$VM_NAME" 2>/dev/null)" = "shut off" ] && virsh start "$VM_NAME" >/dev/null; sleep 20; done ) &
    keeper=$!
  fi
  log "waiting for the node to boot the discovery ISO and register in the Red Hat console"
  for i in $(seq 1 120); do
    hosts=$(ocm GET "$A/infra-envs/$OCM_INFRA_ID/hosts"); [ "$(echo "$hosts" | jget 0/id)" != "" ] && break; sleep 15
  done
  hid=$(echo "$hosts" | jget 0/id); [ -n "$hid" ] || die "the node did not register within 30 min (check its console: does it boot the ISO, reach the internet?)"
  ok "node registered: $(echo "$hosts" | python3 -c 'import json,sys;h=json.load(sys.stdin)[0];i=json.loads(h.get("inventory") or "{}");print(i.get("cpu",{}).get("count","?"),"CPUs,",round(i.get("memory",{}).get("physical_bytes",0)/2**30),"GiB,",len(i.get("disks",[])),"disks")')"
  want=/dev/vda; [ $MODE = baremetal ] && want=$INSTALL_DISK
  if [ -n "$want" ]; then
    disk=$(echo "$hosts" | python3 -c '
import json, sys
h = json.load(sys.stdin)[0]; want = sys.argv[1]
for d in json.loads(h.get("inventory") or "{}").get("disks", []):
    if want in (d.get("path"), d.get("by_path"), d.get("by_id"), "/dev/" + d.get("name", "")):
        print(d.get("id") or d.get("by_id") or d.get("path")); break' "$want")
    [ -n "$disk" ] || die "the node has no disk $want (see the disks in the Red Hat console)"
    ocm PATCH "$A/infra-envs/$OCM_INFRA_ID/hosts/$hid" "$(jobj disks_selected_config:="[{\"id\": \"$disk\", \"role\": \"install\"}]")" >/dev/null
  fi
  for i in $(seq 1 120); do
    cl=$(ocm GET "$A/clusters/$OCM_CLUSTER_ID"); hosts=$(ocm GET "$A/infra-envs/$OCM_INFRA_ID/hosts")
    st=$(echo "$cl" | jget status); [ "$st" = ready ] && break
    [ $((i % 8)) = 1 ] && { echo "  cluster status: $st - waiting for the node's checks:"; host_report "$hosts" "$cl"; } | tee -a "$TLOG"
    sleep 15
  done
  [ "$st" = ready ] || { host_report "$hosts" "$cl"; die "the cluster is not ready to install after 30 min (failing checks above)"; }
  path=$(echo "$hosts" | jget 0/installation_disk_path)
  [ $MODE = baremetal ] && [ "$path" = "$DATA_DEVICE" ] && die "the installer picked $path, which you named as the data disk: re-run with an explicit install disk"
  ok "all checks passed; installing to $path"
  ocm POST "$A/clusters/$OCM_CLUSTER_ID/actions/install" >/dev/null
  log "installing Red Hat CoreOS + OpenShift through the Red Hat console (45-75 min)"
  for i in $(seq 1 400); do
    cl=$(ocm GET "$A/clusters/$OCM_CLUSTER_ID"); st=$(echo "$cl" | jget status)
    pct=$(echo "$cl" | jget progress/total_percentage); info=$(echo "$cl" | jget status_info)
    [ "$st $pct" != "$last" ] && { echo "  $(date +%T)  ${pct:-0}%  $st - ${info:0:100}" | tee -a "$TLOG"; last="$st $pct"; }
    case $st in installed) break ;; error|cancelled) die "installation $st: $info" ;; esac
    sleep 30
  done
  [ "$st" = installed ] || die "installation did not finish within 200 min (status $st)"
  mkdir -p "$WORK/install/auth"; chmod 700 "$WORK/install"
  ( umask 077
    ocm GET "$A/clusters/$OCM_CLUSTER_ID/downloads/credentials?file_name=kubeconfig" > "$KCFG"
    ocm GET "$A/clusters/$OCM_CLUSTER_ID/downloads/credentials?file_name=kubeadmin-password" | tr -d '\n' > "$WORK/install/auth/kubeadmin-password" )
  touch "$WORK/install-finished"; [ -n "$keeper" ] && kill $keeper 2>/dev/null || true
  if [ $MODE = baremetal ]; then
    [ -n "${RF_VMEDIA:-}" ] && rf_code POST "$RF_VMEDIA/Actions/VirtualMedia.EjectMedia" >/dev/null || true
    systemctl stop nai-ocp-iso >/dev/null 2>&1 || true; ok "virtual CD released"
  fi
  for i in $(seq 1 30); do oc_ get nodes >/dev/null 2>&1 && break; sleep 10; done
  oc_ get nodes | tee -a "$TLOG"
  local c m; c=$(oc_ get nodes -o jsonpath='{.items[0].status.capacity.cpu}'); m=$(oc_ get nodes -o jsonpath='{.items[0].status.capacity.memory}'); m=${m:-0Ki}
  [ "${c:-0}" -ge 40 ] || warn "node has $c CPUs: NAI's platform reserves ~19 cores, endpoints may not fit"
  ok "OpenShift installed; node capacity: $c CPUs, $(( ${m%Ki} / 1048576 )) GiB memory"
}

# ---------------------------------------------------------------- remote: run the VM setup on another server
remote_run() {
  ssh_opts
  local seed=$STATE/remote-seed.conf rc boot1 boot2 i v
  log "preparing $RHOST"
  rs "mkdir -p -m 700 /var/lib/nai-ocp"
  rcp "$SELF" "$REMOTE_SCRIPT"; rs "chmod 700 $REMOTE_SCRIPT"; rec "REMOTEFILE $REMOTE_SCRIPT"
  [ "$INSTALL_METHOD" = assisted ] && { rcp "$STATE/ocm-token" /var/lib/nai-ocp/ocm-token; rs "chmod 600 /var/lib/nai-ocp/ocm-token"; }
  rcp "$STATE/pull-secret.json" /var/lib/nai-ocp/pull-secret.json; rs "chmod 600 /var/lib/nai-ocp/pull-secret.json"
  if ! rs "test -s /var/lib/nai-ocp/answers.conf"; then   # seed the answers given here; the VM questions are asked there
    : > "$seed"; for v in INSTALL_METHOD NAI_TAR_SRC NAI_TAR_SRC_BYTES NAI_CHARTS_SRC NAI_CHARTS_SRC_BYTES OCP_VERSION OCP_RELEASE; do
      [ -n "${!v:-}" ] && printf '%s=%q\n' "$v" "${!v}" >> "$seed"; done
    printf 'MODE=vm\n' >> "$seed"; chmod 600 "$seed"
    rcp "$seed" /var/lib/nai-ocp/answers.conf; rs "chmod 600 /var/lib/nai-ocp/answers.conf"; rm -f "$seed"
  fi
  ok "script, Red Hat credential and answers copied to $RHOST:$REMOTE_SCRIPT"
  while :; do
    boot1=$(rs cat /proc/sys/kernel/random/boot_id)
    log "running the setup on $RHOST (its output follows)"
    rc=0; ssh "${SSHO[@]}" -t "root@$RHOST" "NAI_CONTROLLED=1 $REMOTE_SCRIPT" || rc=$?
    if rs "test -f /var/lib/nai-ocp/done/nai" 2>/dev/null; then ok "setup on $RHOST finished"; return; fi
    if [ $rc = 0 ]; then
      rs "test -f /var/lib/nai-ocp/need-reboot" 2>/dev/null \
        && { echo "  $RHOST needs a reboot. Reboot it when convenient, then run 'sudo $SELF' here again."; exit 0; }
      echo "  the setup on $RHOST stopped before finishing; run 'sudo $SELF' here again to continue."; exit 0
    fi
    if [ $rc = 255 ]; then   # connection dropped: a reboot the operator agreed to, or a network break
      log "lost the connection to $RHOST; waiting for it to come back (up to 20 min)"
      for i in $(seq 1 120); do rs true 2>/dev/null && break; sleep 10; done
      boot2=$(rs cat /proc/sys/kernel/random/boot_id 2>/dev/null) || die "$RHOST did not come back; check its console, then run 'sudo $SELF' again"
      [ "$boot1" != "$boot2" ] && { ok "$RHOST rebooted; continuing there"; continue; }
      die "the connection to $RHOST dropped; run 'sudo $SELF' again to continue"
    fi
    die "the setup on $RHOST failed (exit $rc); its log: ssh root@$RHOST tail -50 /var/lib/nai-ocp/run.log"
  done
}

    local g=""; for i in $(seq 1 90); do g=$(oc_ get nodes -o jsonpath='{.items[0].status.allocatable.nvidia\.com/gpu}'); [ -n "$g" ] && [ "$g" != 0 ] && break; sleep 20; done
    [ -n "$g" ] && [ "$g" != 0 ] && ok "nvidia.com/gpu: $g" || warn "GPU not allocatable yet (oc get pods -n nvidia-gpu-operator)"
  else
    ok "CPU-only: NVIDIA GPU Operator not installed (NAI endpoints run on CPU)"
  fi
}

registry() {   # own registry on a free port (never reuses another tool's registry, e.g. NKP's on :5000)
  if [ -z "${REG:-}" ] || ! curl -fsS "http://$REG/v2/" >/dev/null 2>&1; then
    local rt p=5001; rt=$(command -v podman || command -v docker)
    while ! port_free $p; do p=$((p + 1)); done
    REG=$SVC_IP:$p; save REG "$REG"
    $rt image inspect docker.io/library/registry:2 >/dev/null 2>&1 || $rt pull -q docker.io/library/registry:2 >/dev/null
    mkdir -p "$DATA/registry"; $rt rm -f nai-ocp-registry >/dev/null 2>&1 || true
    $rt run -d --name nai-ocp-registry --restart=always --network host -e REGISTRY_HTTP_ADDR=0.0.0.0:$p -v "$DATA/registry:/var/lib/registry:Z" docker.io/library/registry:2 >/dev/null   # host network: no NAT rules a firewall reload can wipe
    rec "REGISTRY $(basename "$rt") nai-ocp-registry"
    [ "$(basename "$rt")" = podman ] && systemctl enable --now podman-restart.service >/dev/null 2>&1 || true
    fw_allow "$p" tcp; sleep 3
  fi
  curl -fsS "http://$REG/v2/" >/dev/null || die "registry $REG not reachable"
  ok "registry http://$REG"
}

ocp_prepare() {
  registry_ensure
  oc_ apply -f - >/dev/null <<EOF
apiVersion: config.openshift.io/v1
kind: ImageTagMirrorSet
metadata: {name: nai-registry}
spec: {imageTagMirrors: [{source: docker.io, mirrors: ["$REG"]}]}
---
apiVersion: config.openshift.io/v1
kind: ImageDigestMirrorSet
metadata: {name: nai-registry}
spec: {imageDigestMirrors: [{source: docker.io, mirrors: ["$REG"]}]}
EOF
  oc_ patch image.config.openshift.io/cluster --type merge -p "{\"spec\":{\"registrySources\":{\"insecureRegistries\":[\"$REG\"]}}}" >/dev/null
  sleep 30; oc_ wait mcp/master --for=condition=Updated=True --timeout=30m >/dev/null; ok "docker.io mirrored through $REG"

  helm template x "$WORK/charts/gateway-crds-helm" --set crds.gatewayAPI.enabled=true --set crds.gatewayAPI.channel=standard --set crds.envoyGateway.enabled=false > "$WORK/gwapi.yaml"
  helm template x "$WORK/charts/gateway-crds-helm" --set crds.gatewayAPI.enabled=false --set crds.envoyGateway.enabled=true > "$WORK/eg-crds.yaml"
  local want have b=openshift-ingress-operator-gatewayapi-crd-admission
  want=$(grep -m1 -oE 'bundle-version: v[0-9.]+' "$WORK/gwapi.yaml" | awk '{print $2}')
  have=$(oc_ get crd gateways.gateway.networking.k8s.io -o jsonpath='{.metadata.annotations.gateway\.networking\.k8s\.io/bundle-version}' 2>/dev/null || true)
  if [ -n "$have" ] && [ "$have" != "$want" ] && oc_ get validatingadmissionpolicy $b >/dev/null 2>&1; then
    [ "$GATEWAY_API_OVERRIDE" = yes ] || die "OpenShift locks Gateway API $have; NAI needs $want (set GATEWAY_API_OVERRIDE=yes to override)"
    warn "overriding OpenShift's Gateway API $have with $want (not supported by Red Hat)"
    local try   # the ingress operator recreates its binding within seconds: delete and apply back to back, retry
    for try in $(seq 1 10); do
      oc_ delete validatingadmissionpolicybinding $b --ignore-not-found >/dev/null 2>&1 || true
      oc_ apply --server-side --force-conflicts -f "$WORK/gwapi.yaml" >/dev/null 2>&1 && break
      [ $try = 10 ] && die "OpenShift kept blocking the Gateway API $want CRDs (admission policy $b)"
      sleep 2
    done
  elif [ "$have" != "$want" ]; then oc_ apply --server-side --force-conflicts -f "$WORK/gwapi.yaml" >/dev/null; fi
  oc_ apply --server-side --force-conflicts -f "$WORK/eg-crds.yaml" >/dev/null; ok "Gateway API $want + Envoy Gateway CRDs"

  local ns; for ns in nai-system envoy-gateway-system kserve lws-system opentelemetry-operator-system; do oc_ get ns $ns >/dev/null 2>&1 || oc_ create ns $ns >/dev/null; done
  oc_ adm policy add-scc-to-group privileged system:serviceaccounts:nai-system >/dev/null
  # anyuid (priority 10) keeps root-image users (ClickHouse, iam-ui); pods that set a seccomp profile (Envoy certgen,
  # UID 65532) are refused by anyuid and admitted by nonroot-v2 instead
  for ns in nai-system nai-admin envoy-gateway-system kserve lws-system opentelemetry-operator-system; do
    oc_ adm policy add-scc-to-group anyuid system:serviceaccounts:$ns >/dev/null; oc_ adm policy add-scc-to-group nonroot-v2 system:serviceaccounts:$ns >/dev/null
  done
  oc_ adm policy add-scc-to-user privileged -z csi-nfs-node-sa -n kube-system >/dev/null
  oc_ adm policy add-scc-to-user privileged -z csi-nfs-controller-sa -n kube-system >/dev/null
  ok "security context constraints granted"
}

rwx_storage() {   # NFS export on this host for NAI model storage (RWX)
  local dir=$DATA/nfs line
  if ! command -v exportfs >/dev/null; then
    pkg_list > "$STATE/pkgs.nfs.before"
    case $(pkg_mgr) in
      apt) apt_install nfs-kernel-server ;;
      dnf) dnf install -y -q nfs-utils ;;
    esac
    pkg_new "$STATE/pkgs.nfs.before" | while read -r p; do rec "PKG $p"; done
  fi
  mkdir -p "$dir"; line="$dir $CLIENT_NET(rw,sync,no_subtree_check,no_root_squash)"
  grep -qxF "$line" /etc/exports 2>/dev/null || { echo "$line" >> /etc/exports; rec "EXPORT $line"; }
  systemctl enable --now nfs-server >/dev/null 2>&1 || systemctl enable --now nfs-kernel-server >/dev/null 2>&1
  exportfs -ra; fw_allow 2049 tcp
  helm repo add csi-driver-nfs https://raw.githubusercontent.com/kubernetes-csi/csi-driver-nfs/master/charts >/dev/null 2>&1 || true
  helm repo update >/dev/null
  helm --kubeconfig "$KCFG" upgrade --install csi-driver-nfs csi-driver-nfs/csi-driver-nfs -n kube-system --set externalSnapshotter.enabled=false --wait >/dev/null
  oc_ apply -f - >/dev/null <<EOF
apiVersion: storage.k8s.io/v1

metadata: {name: nai-nfs-storage}
provisioner: nfs.csi.k8s.io
parameters: {server: $SVC_IP, share: $dir}
reclaimPolicy: Delete
volumeBindingMode: Immediate
allowVolumeExpansion: true
mountOptions: [nfsvers=4.1, hard]
EOF
  ok "RWX storage class nai-nfs-storage on $SVC_IP:$dir"
}

hinst() {   # release chart namespace timeout [helm args]: install/upgrade, wait until ready; on failure show why
  local r=$1 c=$2 n=$3 t=$4; shift 4
  helm --kubeconfig "$KCFG" upgrade --install "$r" "$c" -n "$n" --wait --timeout "$t" "$@" >/dev/null 2>"$WORK/helm-$r.err" && return 0
  { echo "  NAI component '$r' (namespace $n) did not become ready within $t:"
    tail -3 "$WORK/helm-$r.err" | sed 's/^/    helm: /'
    oc_ get pods -n "$n" --no-headers 2>/dev/null | awk '$3 != "Running" && $3 != "Completed" {print "    pod: " $1 "  " $3}'
    oc_ get events -n "$n" --field-selector type=Warning --sort-by=.lastTimestamp --no-headers 2>/dev/null | tail -5 | cut -c1-220 | sed 's/^/    event: /'
  } | tee -a "$TLOG"
  die "NAI component $r failed (details above); fix the cause and run the script again to continue"
}

verify() {   # end-to-end check: cluster, GPU, every NAI pod, and the NAI login page through the cluster's route
  local i bad url=https://nai.apps.$CLUSTER_NAME.$BASE_DOMAIN/nai code ns n
  oc_ get clusterversion version -o jsonpath='{.status.conditions[?(@.type=="Available")].status}' | grep -q True \
    && ok "OpenShift $(oc_ get clusterversion version -o jsonpath='{.status.desired.version}') available" || die "OpenShift reports not available (oc get clusterversion)"
  oc_ get nodes --no-headers | awk '{print $2}' | grep -qx Ready && ok "node Ready" || die "the node is not Ready (oc get nodes)"
  if use_gpu; then
    n=$(oc_ get nodes -o jsonpath='{.items[0].status.allocatable.nvidia\.com/gpu}')
    [ "${n:-0}" -ge 1 ] && ok "GPUs allocatable for endpoints: $n" || warn "no GPU allocatable yet (oc get pods -n nvidia-gpu-operator)"
  fi
  for i in $(seq 1 60); do   # up to 15 min for every NAI pod to be running or completed
    bad=$(for ns in envoy-gateway-system kserve lws-system opentelemetry-operator-system nai-system nai-admin; do
            oc_ get pods -n $ns --no-headers 2>/dev/null | awk -v ns=$ns '$3 != "Completed" && ($3 != "Running" || split($2, r, "/") && r[1] != r[2]) {print ns "/" $1 " " $2 " " $3}'
          done)
    [ -z "$bad" ] && break; sleep 15
  done
  [ -z "$bad" ] && ok "all NAI pods running ($(for ns in envoy-gateway-system kserve lws-system opentelemetry-operator-system nai-system nai-admin; do oc_ get pods -n $ns --no-headers 2>/dev/null; done | wc -l) pods)" \
    || { echo "$bad" | sed 's/^/    not ready: /' | tee -a "$TLOG"; warn "some NAI pods are not ready after 15 min (listed above)"; }
  for i in $(seq 1 20); do
    code=$(curl -sk -m 10 -o /dev/null -w '%{http_code}' --resolve "nai.apps.$CLUSTER_NAME.$BASE_DOMAIN:443:$NODE_IP" "$url" || true)
    [[ $code =~ ^(200|30[1-8])$ ]] && break; sleep 15
  done
  [[ $code =~ ^(200|30[1-8])$ ]] && ok "NAI login page answers at $url (HTTP $code)" || warn "NAI login page not answering yet at $url (HTTP $code)"
}

uninstall() {   # --yes: no questions, no reboot   --confirmed: skip 'wipe' (asked by a controller), report reboot via exit 3
  local arg=${1:-} assume_yes=no confirmed=no
  [ "$arg" = --yes ] && { assume_yes=yes; confirmed=yes; }; [ "$arg" = --confirmed ] && confirmed=yes
  # only what this script recorded is removed: a VM or files created by other tools are never touched
  [ -s "$MANIFEST" ] || { echo "nothing installed by this script (no manifest in $STATE)"; rm -rf "$STATE"; exit 0; }
  case "${MODE:-vm}" in
    remote)
      echo "This runs the uninstall on ${RHOST:-?} (NAI, OpenShift, the VM, packages, GPU reservation, the cluster record in"
      echo "the Red Hat console), then removes this controller's SSH key, script copy and helper packages from it." ;;
    baremetal)
      echo "This removes from THIS host: the NAI image registry, the NFS export, the cluster DNS service, the hosts entries,"
      echo "the virtual CD on the BMC, every package this script installed, the cluster record in the Red Hat console, and"
      echo "$STATE (token, IPMI login, ISO)."
      echo "${c_y}The server (${NODE_IP:-?}) keeps OpenShift on its disks and stops working without this host's registry and${c_0}"
      echo "${c_y}NFS share. Reinstall that server (or run this script again) to reuse it.${c_0}" ;;
    *)
      echo "This permanently removes: NAI, OpenShift and Red Hat CoreOS (the VM and its disks), the cluster record in the"
      echo "Red Hat console, the VM network, the local registry and its images, the NFS export, the GPU passthrough"
      echo "reservation, the IOMMU boot setting, every package this script installed, and $STATE." ;;
  esac
  echo "Recorded changes:"; sed 's/^/   /' "$MANIFEST"
  if [ $confirmed = no ]; then local a; a=$(ask "Type 'wipe' to continue"); [ "$a" = wipe ] || { echo "aborted"; exit 1; }; fi
  local reboot=no kind rest redo="" datadirs="" rrc=0
  log "uninstall"
  if [ "${MODE:-}" = remote ]; then   # the server does its own uninstall; then remove what the controller put there
    ssh_opts
    if rs true 2>/dev/null; then
      if rs "test -x $REMOTE_SCRIPT"; then
        ssh "${SSHO[@]}" -t "root@$RHOST" "$REMOTE_SCRIPT --uninstall --confirmed" || rrc=$?
        [ $rrc = 0 ] || [ $rrc = 3 ] || warn "the uninstall on $RHOST reported exit $rrc"
      fi
      local pk; pk=$(awk '$1=="REMOTEPKG"{print $2}' "$MANIFEST" | tr '\n' ' ')
      [ -n "${pk// /}" ] && { rs "command -v apt-get >/dev/null && DEBIAN_FRONTEND=noninteractive apt-get purge -y -qq $pk || dnf remove -y -q $pk" >/dev/null 2>&1 || true; ok "removed $pk from $RHOST"; }
      rs "rm -f $REMOTE_SCRIPT" || true
      local cmt; cmt=$(awk '$1=="REMOTEKEY"{print $2}' "$MANIFEST")
      local again=""; [ $rrc = 3 ] && [ $assume_yes = no ] && [ $INTERACTIVE = 1 ] && yesno "Reboot $RHOST now to give its GPU back to it" n && again="(sleep 3; systemctl reboot) >/dev/null 2>&1 &"
      rs "${cmt:+sed -i '/ $cmt\$/d' ~/.ssh/authorized_keys;} $again" || true
      ok "controller key and script removed from $RHOST${again:+; it is rebooting}"
      [ $rrc = 3 ] && [ -z "$again" ] && echo "  Reboot $RHOST when convenient to give its GPU back."
    else
      warn "$RHOST is not reachable: run '$REMOTE_SCRIPT --uninstall' on it yourself; removing the controller side only"
    fi
  fi
  systemctl disable nai-ocp-resume.service >/dev/null 2>&1 || true
  systemctl stop nai-ocp-iso >/dev/null 2>&1 || true
  if grep -qx "VM $VM_NAME" "$MANIFEST" && command -v virsh >/dev/null && virsh dominfo "$VM_NAME" >/dev/null 2>&1; then
    virsh destroy "$VM_NAME" >/dev/null 2>&1 || true
    virsh undefine "$VM_NAME" --nvram --remove-all-storage >/dev/null 2>&1 || virsh undefine "$VM_NAME" --nvram >/dev/null
    ok "VM $VM_NAME with Red Hat CoreOS, OpenShift and NAI removed (disks deleted)"
  fi
  while read -r kind rest; do                                     # undo recorded changes, newest first
    case $kind in
      NET)       virsh net-destroy "$rest" >/dev/null 2>&1 || true; virsh net-undefine "$rest" >/dev/null 2>&1 || true; ok "VM network $rest removed" ;;
      REGISTRY)  local rt=${rest%% *} rn=${rest#* }; "$rt" rm -f "$rn" >/dev/null 2>&1 || true; ok "registry container $rn removed" ;;
      EXPORT)    grep -vxF "$rest" /etc/exports > /etc/exports.tmp || true; cat /etc/exports.tmp > /etc/exports; rm -f /etc/exports.tmp
                 exportfs -ra 2>/dev/null || true; ok "NFS export removed" ;;
      HOSTS)     grep -vxF "$rest" /etc/hosts > /etc/hosts.tmp || true; cat /etc/hosts.tmp > /etc/hosts; rm -f /etc/hosts.tmp ;;
      EXPORTCLIENT) # "<path> <client(opts)>": remove one client from a shared export line, keep the others
                 local ep=${rest%% *} ec=${rest#* }
                 python3 - "$ep" "$ec" <<'PY'
import sys
path, client = sys.argv[1:]
out = []
for line in open("/etc/exports"):
    parts = line.split()
    if parts and parts[0] == path and client in parts:
        parts.remove(client)
        line = " ".join(parts) + "\n" if len(parts) > 1 else ""
    out.append(line)

status() {
  echo "State: $STATE"
  if [ -f "$CONF" ]; then
    echo "Deployment: ${MODE:-?}, OpenShift ${OCP_RELEASE:-?}${OCM_CLUSTER_ID:+, console cluster $OCM_CLUSTER_ID}"
    [ "${MODE:-}" = vm ] && echo "VM: ${VM_VCPUS:-?} vCPU, ${VM_RAM_GB:-?} GB, disks ${OS_DISK_GB:-?}+${DATA_DISK_GB:-?} GB in ${DATA:-?}; GPUs: ${GPU_BDFS:-none (CPU-only)}"
    [ "${MODE:-}" = baremetal ] && echo "Server: IPMI ${BMC_HOST:-?}, node ${NODE_IP:-?}, disks ${INSTALL_DISK:-auto} + ${DATA_DEVICE:-?}; GPUs: ${BM_GPU:-?}"
  fi
  echo "Finished stages:"; ls -1tr "$DONE" 2>/dev/null | sed 's/^/  /'
  [ -s "$MANIFEST" ] && { echo "Recorded changes:"; sed 's/^/  /' "$MANIFEST"; }
  if [ "${MODE:-}" = remote ]; then ssh_opts; echo "--- on $RHOST:"; rs "$REMOTE_SCRIPT --status" 2>/dev/null || echo "  (not reachable)"; return; fi
  if grep -qx "VM $VM_NAME" "$MANIFEST" 2>/dev/null; then virsh dominfo "$VM_NAME" 2>/dev/null | grep -E "State|CPU\(s\)|Max memory" || true
  elif command -v virsh >/dev/null && virsh dominfo "$VM_NAME" >/dev/null 2>&1; then echo "A VM named $VM_NAME exists but was not created by this script (not managed)."; fi
  [ -f "$KCFG" ] && oc_ get nodes 2>/dev/null || true
}
